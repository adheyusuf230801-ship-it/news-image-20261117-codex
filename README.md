A drawn newspaper front page for Tuesday 17 November 2026, covering six supplied news stories. All lettering and pictograms are rasterized by the program; no photographs, fonts, packages, or external assets are loaded.

Run with Python 3.13 (standard library only):

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The deterministic 1024 by 1024 PNG is written to `out/entry.png`. Without the environment variable, the destination is `/output/entry.png`. No network access is used.
